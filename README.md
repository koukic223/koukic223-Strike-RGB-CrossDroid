# Strike RGB CrossDroid

**Strike RGB CrossDroid** is a universal Android RGB lighting and visual effects engine designed for Android devices from legacy ARMv7 phones to modern ARM64 and x86 devices.

It combines **RGB LED control, Light Flow, notification lighting, AOD themes, Screen Sync, Ambilight, camera flash effects, and customizable lighting animations** in one Android application.

### Features

* 🌈 RGB Light Flow and smooth HSV color transitions
* 💡 Breathing, Pulse, Heartbeat, Wave, Strobe, Fire, Aurora and Sparkle effects
* 🔔 Per-app notification lighting
* 🌙 Always-On Display (AOD) themes
* 🖥️ Screen Sync and Ambilight effects
* 📸 Camera flash lighting effects
* 🎨 Custom effects and presets
* 🔮 Liquid Glass and visual themes
* 🔐 Root and Magisk hardware control
* 📱 ARMv7-A, ARM64-v8a, x86 and x86_64 support
* ⚡ Performance modes for low-end Android and Android Go devices
